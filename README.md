# HUD
The visible parts of my invisible desktop UI
## We have speed.
The Strix Halo's iGPU is so fast that I can put up a
translucent overlay and remove it, instantly. So, I could have
some information screens, To-dos, Schedule, etc, bound to key-down and disappearing on key-up.

Original idea includes automatic retouching of search queries to force better query-like behavior.
Cheap magnifier just echoes everything and submits upon <return> or <enter>
Hacky but worth trying: first letter of line followed by space is special:
g means this is a google query. quote all parameters.
a means google query with site set to amazon
p means default perplexity query like the firefox search pluging.
e means google query of eBay, so, google syntax.
i means imdb.com/search check url first.
